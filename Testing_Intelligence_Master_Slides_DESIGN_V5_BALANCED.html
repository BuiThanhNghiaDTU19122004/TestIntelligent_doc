AWS CodeBuild + Schemathesis & Playwright API
•
Schemathesis (Fuzzing tự động - Stateless): Đọc file OpenAPI spec từ PR, tự sinh hàng nghìn input dị biệt (số âm, chuỗi dài, null, overflow) bắn vào API để tìm lỗi HTTP 500 và vi phạm schema mà không cần viết test tay.
