GIẢI PHÁP 1 · API TESTING $0.005 / PHÚT BUILD
AWS CodeBuild + Schemathesis & Playwright API
•
Schemathesis (Fuzzing tự động - Stateless): Đọc file OpenAPI spec từ PR, tự sinh hàng nghìn input dị biệt (số âm, chuỗi dài, null, overflow) bắn vào API để tìm lỗi HTTP 500 và vi phạm schema mà không cần viết test tay.
•
Playwright API (Chức năng chuỗi - Stateful): Bù đắp điểm yếu của Schemathesis bằng cách chạy kịch bản luồng nghiệp vụ liên hoàn (Login → Lấy Token → Tạo đơn → Verify). Dùng chung context với UI test.
Tại sao loại bỏ Postman & REST Assured? Postman cần người viết tay và bảo trì collection; REST Assured ràng buộc JVM nặng nề, khởi động chậm, không phù hợp cho serverless micro-runner.
Evidence S08: File JSON ghi nhận endpoint lỗi HTTP 500 kèm cURL command tái hiện lỗi ngay lập tức.

GIẢI PHÁP 3 · SECURITY & RISK 0Đ BẢN QUYỀN · ~$0.0008/PR
AWS CodeBuild + Semgrep & Trivy
•
Semgrep (SAST trên Git Diff): Quét trực tiếp đoạn code thay đổi trong 2–5 giây; bắt lỗi OWASP Top 10, SQLi, XSS, rò rỉ API Keys. Tự viết custom rules bằng YAML.
•
Trivy (SCA & Secrets): Quét các tệp manifest (package.json, pom.xml) đối chiếu cơ sở dữ liệu thế giới tìm mã CVE nguy hiểm của thư viện bên thứ 3.
ĐIỂM NHẤN: Tại sao thay thế Amazon CodeGuru? CodeGuru đã dừng hoạt động từ 20/11/2025. Người kế nhiệm là Amazon Q Developer thiết kế cho người dùng IDE và thu phí $19/user/tháng. TI là API ngầm nên Semgrep + Trivy chạy CLI siêu tốc là lựa chọn hoàn hảo nhất!
Evidence S08: File JSON danh sách lỗ hổng định lượng nạp vào evaluate.py để tính Risk Tier chính xác 100%.
GIẢI PHÁP 4 · DATABASE TESTING < $0.02 / LẦN CHẠY
Aurora Serverless v2 Clone + ECS Fargate
•
Aurora Cloning (Copy-on-write): Nhân bản DB Staging hàng trăm GB thành bản sao độc lập trong < 60 giây. Dung lượng ban đầu = $0, chỉ tốn phí khi ghi mới.
•
Flyway (Migration Execution): Chạy script .sql mới của PR lên bản clone để kiểm tra cú pháp, tính tương thích ngược và thời gian lock bảng.
